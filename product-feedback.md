# Product Feedback

> Trigger: When the user shares feedback, a feature request, or a complaint about the internship experience or platform.

# Steps
1. Ask the customer to describe their feedback, feature request, or complaint in detail. If they have already provided these details, skip to the next step.
2. Ask the customer how this issue or suggestion impacts their internship experience (e.g., if it blocks their progress on projects or is a minor inconvenience).
3. Ask how frequently they encounter this issue, or how often they would use the requested feature.
4. Ask if they have any specific suggestions on how the Decode Labs platform or program could be improved to resolve this.
5. Compile the gathered information into a structured feedback report. *(Note: There is no direct database or ticketing integration connected yet; once one is set up, this report will be submitted automatically).* {{todo:high:Determine where product feedback reports should be sent or logged, such as an email address, CRM, or ticketing tool}}
6. Thank the user for helping improve the Decode Labs internship experience and let them know their feedback has been shared with the team.
